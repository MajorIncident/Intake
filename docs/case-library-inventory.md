# KT / MIM Case Library source inventory

This is the **authoring backlog**, not a public distribution list and not a claim that all cases have completed worked solutions. Master tracker: [#353](https://github.com/MajorIncident/Intake/issues/353). Current source: [KT Application Coach official case registry](https://github.com/MajorIncident/kt-application-coach/blob/main/skill/kt-application-coach/references/case-registry.md). Source families are not interchanged or merged without evidence.

The interface uses four **library tabs**: PSDM, ATS, Legacy, and MIM. **Legacy** contains two clearly identified source subfamilies: 20 retained official legacy cases, plus 16 Problem Analysis / human-performance examples from *The New Rational Manager* (2021). **MIM** is reserved for Intake-native major-incident cases, not an invented KT source category. Shared PSDM/ATS identities are counted once. The 2021 source examples are not asserted to be revised PSDM/ATS cases.

## Per-case acceptance record

Each record should eventually have: (1) actual verified participant source and any role/stage packets; (2) completed source-faithful Full solution in the **Intake MIM-superset schema**, or an explicit source-defined exercise stopping point when no True Cause exists; (3) introductory **inline participant reader** using only appropriately released source facts; (4) original/approved diagrams or accessible original redrawn diagrams *only if licensed and safe*, served through the correct authorized source; (5) exact named-case regression and Classroom-stage tests; (6) verification of runtime, privacy/copyright, media readability and official source provenance.

The first tranche plus reader-first follow-up on [PR #354](https://github.com/MajorIncident/Intake/pull/354) adds source labels, filters, **explicit participant-reading-first navigation** and source-grounded paraphrased in-app reading for the five existing Intake records. These are learner-safe, structured adaptations, **not copied official participant pages or imagery**. Mrs. Walther's Square Donuts contains orientation and the later *The Problem* handout in the same case, with a closed self-study disclosure; the authorized Student GET catalog withholds the later section. The Full reference follows a separate Continue action. Paytrix is an Intake-native MIM example, not an official KT PSDM/ATS case, documented separately in [KT's companion integration index](https://github.com/MajorIncident/kt-application-coach/blob/main/docs/INTAKE_MIM_CASE_LIBRARY.md) (PR #575). Full participant packet conversions, source-by-source solution audits and protected media are further tranches. Until license/asset delivery is confirmed, do not copy original KT PDF pages/figures into the public browser bundle. The current Student staged reference already receives release-filtered content from its authenticated exercise API; the library must never bypass that.

**Priority content batches:** PSDM (Distributor Complaints, Precision Problems, Data Debacle, Typhoon Compressor), then ATS (ArmorTex, Hefto Hoist, New Water Heater), then remaining source families, keeping source-defined Q/IS and discovery staging. Reconcile any date/page/fact differences from the original authorized materials before marking a case content-audited.
